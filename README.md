# 見えるC言語（ウェブアプリ版）

C言語を1行ずつ動かして、変数の箱やメモリの中身を見ながら学べる教材です。
スマホやパソコンのホーム画面に入れて、アプリのように使えます。一度開けば、ネットがなくても動きます。

## 入っているファイル

| ファイル | 役目 |
|---|---|
| `index.html` | アプリ本体（教材・C言語を動かす仕組み・画面） |
| `manifest.webmanifest` | アプリの名前・アイコン・色の設定 |
| `sw.js` | オフラインで動かすための仕組み（Service Worker） |
| `icons/` | ホーム画面のアイコン（ロゴ案A） |

## GitHub Pages で公開する手順（無料）

1. GitHub にログインし、右上の「+」→「New repository」。
   名前は例えば `mieru-c`、公開設定は **Public** にして作成する。
2. 作ったリポジトリで「Add file」→「Upload files」。
   この zip を展開した中身（`index.html`・`manifest.webmanifest`・`sw.js`・`icons` フォルダ）を
   **フォルダごとではなく中身を**ドラッグして、「Commit changes」。
3. リポジトリの「Settings」→ 左の「Pages」。
   「Branch」を `main`、フォルダを `/ (root)` にして「Save」。
4. 1〜2分待つと、`https://（ユーザー名）.github.io/mieru-c/` で開けるようになる。

## ホーム画面に入れる方法

- **iPhone / iPad（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：画面上部の「アプリとして入れる」ボタン、またはメニュー →「アプリをインストール」
- **パソコン（Chrome / Edge）**：画面上部の「アプリとして入れる」ボタン、またはアドレスバー右のインストールのアイコン

## 中身を更新したとき

`index.html` などを新しいものに差しかえてアップロードすれば、次に開いたときに新しい版になります
（ネットにつながっているときに開くと最新を読みこみます）。

## 注意

- **AIせんせいは、この版では表示されません。** AIせんせいは claude.ai の上で開いたときだけ使える仕組みのためです。
  ほかの機能（1行ずつ実行・メモリ表示・レッスン・クイズ・採点）はすべて使えます。
- 進みぐあい（クリアした演習・書いたプログラム）は、その端末のブラウザの中にだけ保存されます。
- 文字のデザイン（フォント）はインターネットから読みこみます。はじめてオフラインで開いたときは、
  ふつうの文字で表示されますが、動きには影響しません。
- `file://` で直接 `index.html` を開いても動きますが、オフライン機能とホーム画面への追加は、
  `https://` で公開したときだけ使えます。
